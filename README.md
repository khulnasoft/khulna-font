# Khulna

### Typeface by KhulnaSoft

Khulna is an open-source typeface family designed for modern interfaces, developer tools, code, documentation, and the web.

## Families

- Khulna Sans
- Khulna Mono
- Khulna Pixel

## Status

Khulna is currently under development.

```bash
pnpm validate
```
