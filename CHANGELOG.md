# Changelog

All notable changes to Khulna will be documented in this file.

## [0.1.0] — 2026-09-26

### Added
- Khulna Sans + Khulna Mono UFO sources (120 / 123 glyphs)
- FontMake pipeline: TTF + WOFF2
- OpenType features: liga, kern, calt, case, tnum, pnum, frac, ordn, sups, subs, zero
- Mono stylistic sets: ss01, ss02, ss03
- FontBakery profile
- Next.js website with FontTester
- npm package generation from dist/
- Visual regression snapshots (8 baseline images)
- 11 automated tests (all passing)
