# Design Specification

## Khulna Sans

- Geometric/humanist direction
- x-height, cap height, ascender/descender
- Stroke contrast
- Terminal shapes
- Curves
- Punctuation style
- Numerals
- Spacing philosophy

## Khulna Mono

- Monospace width
- Programming characters
- Distinguishable glyphs: 0/O, 1/l/I, 5/S, 2/Z
- Brackets, operators, arrows
- Box-drawing characters
