# OpenType Features

- Standard ligatures
- Discretionary ligatures
- Tabular and proportional numerals
- Oldstyle numerals
- Fractions, superscript, subscript
- Ordinals
- Case-sensitive punctuation
- Zero styles

## Khulna Mono Features

- cv01: alternate zero
- cv02: alternate 1
- cv03: alternate I
- ss01: programming ligatures
